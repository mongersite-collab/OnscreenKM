# OnscreenKM — سرور امنیتی و سیستم توکن

سرور محافظ سایت KM — بدون هیچ پکیج خارجی (zero dependency)، فقط Node.js.

---

## ۱) اجرا

```bash
cd server
node server.js
```

سپس سایت روی **http://localhost:4173** بالا می‌آید.
همین سرور هم فایل‌های سایت را سرو می‌کند و هم API امنیتی را.

> مهم: سایت را با `python -m http.server` بالا نیاور؛ آن وقت سیستم توکن وارد **حالت آفلاین** می‌شود.

---

## ۲) کد ورود مخصوص دولپر

پیش‌فرض:

```
KM-OWNER-2026-OMEGA-7X4Q
```

در صفحه‌ی ورود روی «◈ ورود دولپر با کد مخصوص» بزن و کد را وارد کن.
نتیجه: حساب با برچسب `DEVELOPER` و **دسترسی نامحدود (∞)** به هر پنج ابزار؛ هیچ توکنی کسر نمی‌شود.

**حتماً عوضش کن** پیش از اینکه سایت را روی اینترنت بگذاری:

```bash
KM_DEV_CODE="کد-دلخواه-خودت" node server.js
```

---

## ۳) روش‌های ورود کاربران

| روش | توضیح |
|---|---|
| ساخت حساب | ایمیل + رمز عبور (حداقل ۸ کاراکتر و یک عدد) |
| ورود | ایمیل + رمز عبور |
| کد جیمیل | کد ۶ رقمی به جیمیل فرستاده می‌شود (بدون رمز) |
| حساب گوگل | دکمه‌ی Google Sign-In |
| کد دولپر | فقط برای خودت — دسترسی نامحدود |

هر حساب تازه، **۳۰۰ دولپر توکن (Dolper Token)** هدیه می‌گیرد و هر روز که وارد شود **۱۰ دولپر توکن** دیگر.

همه‌ی ابزارها از **یک مخزن مشترک (دولپر توکن دون)** کم می‌کنند:

| ابزار | هزینه‌ی هر خروجی |
|---|---|
| ساخت عکس | ۱۰ دولپر توکن |
| ساخت تصویر / ویدیو | ۲۰ دولپر توکن |
| ساخت تامنیل | ۲۰ دولپر توکن |
| ادیت ویدیو | ۲۵ دولپر توکن |
| ادیت عکس | ۱۰ دولپر توکن |

تنظیم از طریق `.env`: `KM_FREE_TOKENS`، `KM_DAILY_TOKENS`، `KM_COST_IMAGE|VIDEO|THUMB|EDITVID|EDITIMG`.

## ۴) تنظیم ارسال کد به جیمیل (SMTP)

بدون تنظیم SMTP، سرور کد را در **کنسول خودش** چاپ می‌کند (برای تست).

برای ارسال واقعی با Gmail:

1. در حساب گوگل، **2-Step Verification** را روشن کن.
2. برو به **Google Account → Security → App passwords** و یک App Password بساز (۱۶ حرفی).
3. سرور را این‌طور اجرا کن:

```bash
SMTP_HOST=smtp.gmail.com \
SMTP_PORT=465 \
SMTP_USER=zarvandikomeil@gmail.com \
SMTP_PASS="کد-۱۶-حرفی-اپ-پسورد" \
SMTP_FROM="OnscreenKM <zarvandikomeil@gmail.com>" \
node server.js
```

رمز اصلی حساب گوگل کار نمی‌کند — حتماً App Password.

---

## ۵) تنظیم ورود با گوگل

1. برو به <https://console.cloud.google.com>
2. **APIs & Services → Credentials → Create Credentials → OAuth client ID → Web application**
3. در بخش *Authorized JavaScript origins* آدرس سایتت را بگذار (مثلاً `http://localhost:4173`).
4. Client ID را بده به سرور:

```bash
KM_GOOGLE_CLIENT_ID="xxxxx.apps.googleusercontent.com" node server.js
```

تا وقتی این تنظیم نشده، دکمه‌ی گوگل کاربر را به روش «کد جیمیل» هدایت می‌کند.

---

## ۶) تغییر هزینه‌ی توکن هر ابزار

هزینه‌ها: عکس ۱۰ · تصویر/ویدیو ۲۰ · تامنیل ۲۰ · ادیت ویدیو ۲۵ · ادیت عکس ۱۰ دولپر توکن.
وقتی عددهای واقعی را داشتی، فایل `server/config.js` را باز کن و فقط همین بخش را عوض کن:

```js
costs: {
  image:   1,   // هوش مصنوعی ساخت عکس
  video:   1,   // هوش مصنوعی ساخت ویدیو / تصویر متحرک
  thumb:   1,   // هوش مصنوعی ساخت تامنیل
  editvid: 1,   // هوش مصنوعی ادیت ویدیو
  editimg: 1    // هوش مصنوعی ادیت عکس
}
```

یا بدون دست زدن به کد:

```bash
KM_COST_IMAGE=5 KM_COST_VIDEO=20 KM_COST_THUMB=3 \
KM_COST_EDITVID=15 KM_COST_EDITIMG=4 node server.js
```

عددهای جدید فوراً زیر نام هر ابزار در پنل توکن نمایش داده می‌شوند.

---

## ۷) نمایش توکن (بالا سمت چپ)

بعد از ورود، یک کپسول شیشه‌ای در **گوشه‌ی بالا سمت چپ** ظاهر می‌شود:

- مجموع توکن‌ها (یا نماد ∞ برای دولپر)
- با کلیک باز می‌شود و مانده‌ی هر پنج ابزار را با نوار پیشرفت نشان می‌دهد
- هر بار کسر توکن، عدد فلاش می‌زند و پیام «−N توکن» نشان داده می‌شود

---

## ۸) مدیریت کاربران (فقط دولپر)

لیست کاربران:

```bash
curl -H "Authorization: Bearer <session>" http://localhost:4173/api/admin/users
```

هدیه دادن توکن:

```bash
curl -X POST -H "Authorization: Bearer <session>" -H "Content-Type: application/json" \
  -d '{"email":"user@gmail.com","tool":"all","amount":50}' \
  http://localhost:4173/api/admin/grant
```

نامحدود کردن یک کاربر: `{"email":"...","unlimited":true}`

---

## ۹) امنیت پیاده‌سازی‌شده

- رمز عبور با **scrypt** (N=16384) و salt تصادفی هش می‌شود — هیچ‌وقت خام ذخیره نمی‌شود
- سشن با **HMAC-SHA256** امضا و بعد از ۷ روز منقضی می‌شود؛ خروج = ابطال فوری (jti revoke)
- مقایسه‌ی **timing-safe** برای کد دولپر و کدهای ایمیلی
- قفل حساب بعد از ۶ ورود ناموفق به مدت ۱۵ دقیقه
- Rate limit روی ورود، ارسال کد و کسر توکن
- هدرهای امنیتی: CSP، X-Frame-Options، nosniff، Referrer-Policy، Permissions-Policy، COOP (+ HSTS روی HTTPS)
- پوشه‌های `server/`، `backend/`، `native/`، `.git` از بیرون قابل دانلود نیستند (403)
- حفاظت از path traversal در سرو فایل استاتیک
- فایل کاربران با دسترسی `0600` و نوشتن اتمیک

## ۱۰) اجرا روی HTTPS

```bash
KM_TLS_KEY=/path/privkey.pem KM_TLS_CERT=/path/fullchain.pem PORT=443 node server.js
```

## ۱۱) مسیرهای API

| متد | مسیر | کار |
|---|---|---|
| GET | `/api/config` | تنظیمات عمومی (هزینه‌ها، توکن رایگان) |
| GET | `/api/health` | وضعیت سرور |
| POST | `/api/auth/register` | ساخت حساب |
| POST | `/api/auth/login` | ورود |
| POST | `/api/auth/code/request` | ارسال کد ۶ رقمی |
| POST | `/api/auth/code/verify` | تایید کد |
| POST | `/api/auth/google` | ورود با گوگل |
| POST | `/api/auth/dev` | ورود دولپر |
| GET | `/api/me` | اطلاعات حساب و توکن‌ها |
| POST | `/api/spend` | کسر توکن یک ابزار |
| POST | `/api/auth/logout` | خروج |
| GET | `/api/admin/users` | لیست کاربران (دولپر) |
| POST | `/api/admin/grant` | هدیه‌ی توکن (دولپر) |

## ۱۲) حالت آفلاین

اگر سایت را بدون سرور باز کنی (مثلاً دابل‌کلیک روی `index.html`)، صفحه‌ی ورود باز هم کار می‌کند ولی حساب‌ها و توکن‌ها فقط در مرورگر خودت ذخیره می‌شوند (برای تست، نه برای انتشار واقعی).


---

## ۱۳) دولپر توکن دون و کارگاه هوش مصنوعی (نسخه‌ی ۱۴)

- پنل بالا سمت چپ = **دولپر توکن دون**: موجودی کل، نوار پیشرفت، تعرفه‌ی هر ابزار، تعداد دفعات ممکن، هدیه‌ی روزانه و پنج مصرف آخر.
- هر ابزار سه زون دارد: **کارگاه طراحی** ← **خروجی زنده** ← **گالری نتایج**.
- گالری در `localStorage` با کلید `km_gallery_v1` ذخیره می‌شود (حداکثر ۲۴ نتیجه).
- `assets/js/km-lab.js` موتور **KM Vision** است: پرامپت فارسی/انگلیسی را می‌خواند، پالت/حس‌وحال/شدت/تراکم را درمی‌آورد و خودکار تمام تنظیمات ابزار را می‌چیند. کاملاً آفلاین و بدون نیاز به API خارجی.
