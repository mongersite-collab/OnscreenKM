# ONSCREENKM — نسخه v5 (ترکیبی)

این نسخه ترکیب دو سایت است:

- **از نسخه‌ی شما:** صفحه‌ی لودینگ، طراحی شیشه‌ی مایع (Liquid Glass)، هیروی Ken Burns، مانیفست، خط زمانی، ماژول‌ها، پاورقی و هر سه تصویر برند.
- **از نسخه‌ی قبلی:** میدان ذرات متحرک، نشانگر اختصاصی موس، نوار پیشرفت اسکرول، بخش سکانس چهارپرده‌ای، هسته‌ی نورانی با آمار شمارشی، و موتور گفتگوی KM.
- **حذف شد:** بخش ترجمه و دکمه‌ی سه‌زبانه، و لودینگ قبلی.

## اجرا

بهترین راه — با یک سرور محلی:

```bash
cd km-v5
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

دابل‌کلیک روی `index.html` هم کار می‌کند.

## فونت‌ها

| کاربرد | فونت |
|---|---|
| متن فارسی | **Vazirmatn** (وزن 300 تا 900) |
| تیترهای لاتین و اعداد بزرگ | **Space Grotesk** |
| کد، برچسپ‌ها، ریزمتن فنی | **JetBrains Mono** |
| تأکید هنری (ایتالیک) | **Instrument Serif** |

اگر اینترنت نباشد به‌طور خودکار به Noto Sans Arabic / Tahoma برمی‌گردد.

## دستیار KM

- **بدون کلید:** موتور داخلی پاسخ می‌دهد (سلام، اسم، قابلیت‌ها، ساعت).
- **با کلید:** OpenAI ، Claude یا Gemini — کلید فقط در مرورگر شما ذخیره می‌شود.
- **اسم:** همیشه می‌گوید **KM**.
- **محدودیت سرعت:** تا پایان پاسخ، ورودی قفل می‌شود — دیگر کند نمی‌شود.
